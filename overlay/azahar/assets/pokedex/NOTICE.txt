Hoenn Forge offline Pokédex data
================================

species.json is generated by scripts/build-pokedex-db.py from:

  PokeAPI CSV dumps
  https://github.com/PokeAPI/pokeapi
  License: BSD-3-Clause

sprites/{id}.png — classic-style icons pulled from the community PokeAPI/sprites
repo for offline Pokédex UI. Art is Nintendo-owned; not redistributed as a
standalone asset pack outside this app. Prefer regenerating via build script
rather than treating as original work.

Pokémon names, types, and related terminology are trademarks of Nintendo /
Creatures Inc. / GAME FREAK inc. This fan project ships factual game data for
offline companion use only — no ROMs or encryption keys.

OCR uses Google ML Kit Text Recognition (bundled Latin model). See the ML Kit
terms and third-party notices bundled with that dependency.
